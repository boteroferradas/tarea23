# Tarea 23

## InetAddress: Consulta de Dominios e IPs en Java

Pequeño programa que muestra el nombre y la dirección IP del equipo al iniciar.
Permite consultar las ip de cualquier dominio (ej. `www.xunta.gal`, `www.google.com`) y 
clasifica y distingue entre direcciones IPv4 e IPv6. El programa se ejecuta en un bucle
hasta que se escriba "salir" por consola.
